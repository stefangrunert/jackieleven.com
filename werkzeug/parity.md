# HTTP parity: PHP → Go

`parity.py` uses only Python's standard library. It reads the reference sitemap to discover every canonical page in both languages, biography links for the excluded Pastiche chapters, and adds station fragments, translated/legacy routes, language negotiation, HEAD, filters and malformed values. It never sends POST requests.

Create the current v2 baseline (development TLS certificate):

```sh
python3 werkzeug/parity.py --baseline /tmp/jackie-php-baseline-v2 --insecure --assets --report /tmp/jackie-baseline-v2-report.json
```

Compare a running Go server:

```sh
python3 werkzeug/parity.py --baseline /tmp/jackie-php-baseline-v2 --candidate http://127.0.0.1:8080 --insecure --assets --report /tmp/jackie-go-parity-v2-report.json
```

The v2 baseline was captured from clean PHP commit `869442365d26a697f4f630b03ac073d4899055d6`. It has 1,613 cases and a durable ignored copy at `.dev/migration-state/php-baseline-v2`; the original 1,589-case v1 snapshot remains untouched. The added cases cover invalid, duplicate and array-valued `fragment`, wrong-language detail routes, doubled/encoded slashes and safe empty-body `OPTIONS`, `PUT`, `PATCH` and `DELETE` requests. The baseline includes a manifest and compressed response contracts. Later runs reuse it, including when the reference is unavailable. `--refresh` deliberately replaces the baseline; do not use it to make migration differences disappear. `--match /stimmen` and `--limit 20` select smaller diagnostic runs. The report contains each failing request and a bounded unified diff; any failure yields exit code 1. Errors are failures, never passes.

Comparison includes status, Content-Type, Content-Language, Location, canonical Link header, X-Robots-Tag, Vary and Retry-After. HTML comparison retains ordered element/text events with sorted attributes. It includes all links, IDs, ARIA, SEO, hreflang and JSON-LD. XML keeps element order and compares namespace-resolved names and attributes.

Normalization is deliberately limited:

- HTML comments are ignored. Ordinary HTML whitespace is collapsed at each parser text event, but NBSP and other typographic spaces remain content. A separate block-local `inline_text` contract retains rendered word separation across inline element boundaries, so `Hello <em>x</em> world` differs from `Hello<em>x</em>world` and whitespace between adjacent inline siblings is not silently discarded. Source indentation between block elements remains irrelevant.
- HTML attribute order and self-closing syntax on HTML void elements do not matter. Entities are decoded by HTMLParser.
- Script/style/pre/textarea content is preserved; JSON-LD is decoded and compared as structured JSON, preserving array order.
- Only the value of `input[name=token]` is replaced by a marker because contact CSRF is random.
- Only the `v` query parameter on `/assets/` href/src values is removed because checkout modification times differ. `--assets` separately compares all referenced CSS/JS contents (including line order); CSS text line endings are normalized, binary responses use SHA-256.
- `data-seo` and `data-alternativen` are parsed as structured JSON because the shipped JavaScript consumes both with `JSON.parse`. Object key order and JSON escape spelling therefore do not matter; array order and values still do. No other `data-*` attribute receives this normalization without matching runtime evidence.
- Content-Type capitalization and semicolon spacing are normalized; text response CRLF becomes LF. Server/Date/Content-Length and session cookie identifiers are not compared.

Limits: the inline-flow check uses HTML block semantics, not computed CSS; flex/grid/display overrides still belong to browser verification. Whitespace solely between replaced inline elements without nearby text is not projected separately. XML comparison is sufficient for the sitemap but currently ignores child tail whitespace, so it must not be treated as a general mixed-content XML comparator. Encoded slash `/de%2Fueber` is an explicit deployment-boundary probe: the reference 404 body is generated by Apache before PHP, so the report records equal safe status and a no-leak check under `infrastructure_checks`, with `body_parity_compared: false`; it is never presented as equal application content. The tool does not claim visual equivalence, JavaScript interaction equivalence, contact POST/state/security coverage, cookie semantics, private-file protection or deployment equivalence. Those are independent required checks. Existing PHP `werkzeug/kontakt.php`, Go mocked contact tests and isolated credential-free HTTP contact tests cover sending boundaries. Never valid-submit to the configured reference contact route. Asset checking here covers CSS/JS only; release verification must verify images, scans and fonts too.

Normalizer regression tests:

```sh
python3 -m unittest -v werkzeug/test_parity.py
```

## Isolated contact HTTP parity

`contact_parity.py` must only target two explicitly credential-free loopback servers. Never point it at the configured PHP reference. Start PHP's built-in server with `JACKIE_RESEND_API_KEY`, `JACKIE_TURNSTILE_SITEKEY` and `JACKIE_TURNSTILE_SECRET` explicitly empty, a unique `JACKIE_CONTACT_STATE_DIR`, and a unique `session.save_path`. Start Go with the same three empty variables and its own state directory. Then run:

```sh
python3 werkzeug/contact_parity.py \
  --php http://127.0.0.1:8092 \
  --go http://127.0.0.1:8082 \
  --php-session-dir /tmp/unique-php-sessions \
  --go-state-dir /tmp/unique-go-contact-state \
  --report /tmp/jackie-contact-http-parity-final.json
```

The tool aborts before any POST if either rendered form exposes a public sitekey. With empty configuration, verification and send branches are unreachable. It checks German and English GET, parsed cookie attributes, 48-hex form tokens, missing/invalid/array CSRF, fresh-token timing, scalar and array honeypots, escaped validation echo, array fields, empty-configuration 503, token retention, Retry-After and expiry induced only by editing the isolated state files. It never stores raw cookies or CSRF tokens in the report.

Final isolated result: 15/15 cases passed with zero differences. Report: `/tmp/jackie-contact-http-parity-final.json`; durable ignored copy: `.dev/migration-state/jackie-contact-http-parity-final.json`. The configured PHP reference received no POST, and the temporary PHP isolation server was stopped after the run.
